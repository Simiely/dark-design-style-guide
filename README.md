## dark-homepage-designs.html

深色主页设计风格手册，收录 **28 种深色设计风格**，每种风格包含：

- **完整主页设计稿** — 独立构图，不是同一模板换色（分屏 50/50、全屏终端、HUD 读条、杂志双栏、Bento 砖块、等距场景、哥特尖拱……）
- **延伸页面** — 同一风格延伸到文章页 / 仪表盘 / 价格页 / 画廊页 / 登录页 / 功能展示页
- **组件样式** — 按钮、输入框、开关、徽章、进度条的真实形态
- **界面设计要点** — 布局骨架、hero 占比、边框阴影、动效、图标、避免踩的坑
- **色板** — 风格专属配色，点击复制 hex
- **CSS 变量** — 一键复制整套 `:root` 变量，粘进项目即用
- **补充信息** — 特征标签、字体策略、适用场景、参考案例

## color-palette-guide.html

配色使用速查表，按**情绪 / 风格（主类）× 用途场景（子类）**双维度分类组织。

### 分类结构

- **10 个情绪风格主类**：平静 · 活力 · 奢华 · 极简 · 温暖 · 浪漫 · 复古 · 暗黑 · 赛博 · 自然
- **6 个用途场景子类**：网站 · App · 品牌Logo · 海报 · 包装 · 社交媒体
- **13 个行业标签**：科技互联网 · 商务金融 · 餐饮美食 · 时尚美妆 · 家居生活 · 健康环保 · 文化创意 · 娱乐社交 · 活动会展 · 教育学习 · 婚庆礼仪 · 电商零售 · 运动旅行

### 每套配色包含

- 5 色 HEX 色值（点击复制）
- 色彩比例条（主色 / 辅色 / 点缀色面积分配）
- **深色调 + 浅色调**双版迷你主页示意（导航 + Hero + 按钮 + 卡片区），直接展示配色落地效果
- 适用行业标签

### 交互功能

- Tab 切换 10 个情绪风格大类
- 标签筛选栏——点击行业标签全局跨 Tab 筛选
- 列数切换（1 / 2 / 4 列，自动记忆）
- 点击色块或 HEX 值一键复制

## 使用方式

- **本地**：双击任意 `.html` 文件直接在浏览器打开，完全离线可用
- **部署**：拖进浏览器，或上传到任意静态托管（GitHub Pages / EdgeOne / Vercel……）
- **速查**：每个 HTML 配一份同名 `.md` 速查文档，按场景快速定位

## 文件结构

```
dark-homepage-designs.html  — 深色主页风格手册（28 种风格，零依赖单文件）
dark-homepage-designs.md    — 速查文档（场景定位 + 色值表）
color-palette-guide.html    — 配色使用速查表（242 套配色 + 深浅双版示意）
*.html                      — 后续新增的收集页面，每主题一个 HTML
*.md                        — 每个 HTML 配一份同名速查文档（可选）
README.md                   — 本文件（收录索引 + 各页面说明）
AGENTS.md                   — AI / 未来的你（架构、约定、常见坑）
DEVELOPMENT.md              — 开发者（架构说明、关键问题一坑一篇）
CHANGELOG.md                — 版本变更记录
push-to-github.ps1          — 一键推送脚本（需 GitHub PAT）
```

## 新增一个收集页面

1. 新建 `xxx.html`（零依赖单文件，参考现有页面的结构）
2. （可选）配一份同名的 `xxx.md` 速查文档
3. 在本文档「收录页面」表格登记一行
4. 运行推送脚本上传（会自动更新已存在的文件）
