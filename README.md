# 深色设计风格收集 · Dark Design Style Collection

这是一个**设计风格收集库**:把做网页 / 程序时常用的深色设计风格,逐个整理成**可视化参考页面(HTML)**。需要灵感时打开对应页面,配色、CSS 变量、界面设计方案直接取用,不用每次重新收集。

> **多 HTML 结构**:每个收集主题一个独立 HTML 页面(零依赖、可离线双击打开),后续持续新增,页面越来越多。下表是当前收录的所有页面。

## 这个 HTML 里有什么

`dark-homepage-designs.html` 是一个零依赖、可离线双击打开的单文件手册,收录 **28 种深色设计风格**。每种风格包含:

### 1. 完整主页设计方案(首页预览)
每种风格都有一套**独立构图的主页设计稿**——布局骨架、hero 占比、页面形式各不相同:分屏 50/50、全屏终端、HUD 读条、杂志双栏、Bento 砖块、等距场景、哥特尖拱……不是同一个模板换颜色。

### 2. 延伸页面
同一种风格延伸到另一种真实页面形态:文章页 / 仪表盘 / 价格页 / 画廊页 / 登录页 / 功能展示页,看这套风格在别的场景下怎么延续。

### 3. 组件样式
按钮(主要 / 次要 / 危险)、输入框、开关、徽章、进度条——每种风格下真实组件的圆角、边框、阴影、发光形态。

### 4. 界面设计要点
每风格一张表:布局骨架、hero 占比、边框阴影、动效、图标、以及"避免踩的坑"。

### 5. 色板
风格专属配色,点击色块即可复制 hex。

### 6. CSS 变量
一键复制整套 `:root` 变量(背景三档层次、主次文字、强调色、圆角、字体),粘进项目即用。

### 7. 补充信息
特征标签、字体策略、适用场景、参考案例(Linear / GitHub / Monument Valley / Cyberpunk 2077…)。

## 页面功能

- **搜索** — 按风格名、场景、颜色关键词搜索
- **分类筛选** — 现代极简 / 编辑印刷 / 数字界面 / 艺术文化 / 实验亚文化 / 沉浸展示
- **收藏** — ☆ 收藏到本地,刷新不丢
- **复制** — 点色块复制 hex、点按钮复制整套 CSS 变量
- **速查表** — 底部 28 种风格横向对比(布局 / 圆角 / 边框阴影 / 动效 / hero 占比)

## 使用

- 本地:双击 `dark-homepage-designs.html` 直接在浏览器打开,完全离线可用
- 快速查风格:看同目录 `dark-homepage-designs.md`(按场景定位风格,附色值)
- 网页:拖进浏览器,或部署到任意静态托管即可

## 文件结构

```
dark-homepage-designs.html — 风格手册页(28 种深色主页设计方案,数据驱动,零依赖)
dark-homepage-designs.md   — 该页速查文档(场景定位 + 全部风格色值表)
*.html                     — 后续新增的收集页面,每主题一个 HTML
*.md                       — 每个 HTML 配一份同名速查文档
README.md                  — 本文件(用户 / 访客,含页面索引)
AGENTS.md                  — AI / 未来的你(架构、约定、常见坑)
DEVELOPMENT.md             — 开发者(架构说明、关键问题一坑一篇)
CHANGELOG.md               — 版本变更记录
push-to-github.ps1         — 一键推送脚本(需 GitHub PAT)
```

## 新增一个 HTML 页面

1. 新建 `xxx.html`(零依赖单文件,参考 `dark-homepage-designs.html` 的结构)
2. 配一份同名的 `xxx.md` 速查文档
3. 在本文档「页面索引」登记一行
4. 运行推送脚本上传(会自动更新已存在的文件)
