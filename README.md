# 深色设计风格手册 · Dark Design Style Guide

> 28 种视觉语言各异的深色主页设计方案 —— 纯前端单 HTML,零依赖,双击即用。

做网页/程序时不再需要每次重新收集设计风格:本手册一次收录 **28 种完整主页设计**,每种在**布局骨架、比例结构、组件形态、材质纹理、字体与装饰**上各不相同(不是换色)。

## 效果总览(28 种)

| 分类 | 风格 |
|---|---|
| 现代极简(4) | 瑞士极简 · Bento 模块 · 分屏对比 · 时间线叙事 |
| 编辑印刷(4) | 杂志编辑 · 印刷纸张 · 国风水墨 · 书页章节 |
| 数字界面(7) | 终端 · 玻璃拟态 · 新拟态 · 赛博朋克 HUD · 等距 3D · 侧边栏应用 · 对话界面 |
| 艺术文化(5) | 粗野主义 · 包豪斯 · 装饰艺术 · 哥特 · 构成主义 |
| 实验亚文化(4) | 故障 · 酸性 · 蒸汽波 · 像素 8-bit |
| 沉浸展示(4) | 深空宇宙 · 电影感 · 镀铬金属 · 全息投影 |

## 每种风格的标配

- **首页预览** — 完整主页设计稿(构图/比例/形式各不相同)
- **延伸页面** — 同款风格的其他页面形态(列表/仪表盘/价格/文章/画廊/登录)
- **组件样式** — 按钮/输入框/开关/徽章/进度条
- **界面设计要点** — 布局/hero 占比/边框阴影/动效/图标/避免
- **色板 + CSS 变量** — 点击色块复制 hex,一键复制 `:root` 变量块
- **收藏与搜索** — ☆ 收藏(本地保存)、按风格/场景/颜色关键词搜索

## 快速开始

- 本地:双击 `index.html` 直接用浏览器打开
- 在线:把 `index.html` 内容粘贴到 CodePen / jsFiddle 即可运行
