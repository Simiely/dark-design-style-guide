怎么看懂一种主页设计:五个维度

主页设计的差异来自这五个维度——它们决定"构思",只换配色不算新方案:

① 布局骨架竖向节奏 / 报纸多栏 / 砖块拼贴 / 分屏 / 终端行 / HUD 覆盖 / 几何构图…
② 比例结构hero 占全屏、占 70%、占 40%…;导航-内容-页脚的不同占比与节奏。
③ 组件形态按钮与卡片:直角硬边 / 圆角玻璃 / 浮雕 / 贴纸 / 切角 / 像素边…
④ 材质纹理纸张颗粒 / 玻璃模糊 / 噪点 / 扫描线 / 网格 / 星云 / 液态…
⑤ 字体与装饰衬线 / 无衬线 / 等宽 / 斜切变形 / 几何图形 / 印章 / 放射线…

深色界面设计最佳实践

  • 避免纯黑背景(#000):改用深灰、深蓝、墨绿等"柔和黑",观感更高级、眩光更少。
  • 文字对比度 ≥ 4.5:1(WCAG AA):主文字用 90% 亮度的灰白,次要文字 60% 左右。
  • 层次靠"层级色"而非边框:背景 → 面板 → 内嵌 三档明度拉开层级。
  • 强调色用 1~2 个:大面积霓虹/荧光会疲劳,用单一点缀色。
  • 圆角、阴影、边框要成体系:一种风格里所有组件用同一套策略。
  • 深色下的发光:用强调色的半透明版本做光晕,别用纯白。
  • 图片与图标:深色背景上的图片压暗 15~25% 或加渐变遮罩。
  • 尊重系统偏好:用 prefers-color-scheme: dark + 手动开关。

怎么选主页方案

按产品调性:

  • 开发者工具 / SaaS / 数据后台 → 侧边栏应用、瑞士极简、Bento 模块、对话界面、终端
  • 游戏 / 电竞 / 音乐 / 潮流 → 赛博朋克 HUD、像素 8-bit、蒸汽波、酸性、故障艺术
  • 金融 / 商务 / 品牌官网 → 装饰艺术、瑞士极简、杂志编辑
  • 个人主页 / 作品集 / 极客风 → 终端、粗野主义、包豪斯、等距 3D、时间线叙事、构成主义
  • 健康 / 生活 / 文创 → 玻璃拟态、国风水墨、书页章节、印刷纸张、新拟态
  • 展示 / 叙事 / 首屏 → 电影感、深空宇宙、镀铬金属、全息投影、蒸汽波、分屏对比
